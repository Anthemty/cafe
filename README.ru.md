> Ваш Mac не задаёт дремать — поэтому он называется **cafe**. ☕

Крошечный инструмент в строке меню macOS, не дающий системе засыпать во время
кодинг-сессий с агентами.

Надоело, что Mac засыпает, пока агент долго работает? **cafe** ставит чашку
кофе в вашу строку меню. Кликните, выберите режим — и Mac не уснёт, пока вы
сами не выключите. Цвет иконки говорит о состоянии с одного взгляда — больше
не нужно гадать, работает ли ещё `caffeinate`.

Написан на чистом Rust поверх системного `caffeinate`, **без web view** и
**без зависимостей** помимо самого macOS — только бинарник на ~400 КБ,
живущий в строке меню.

---

## Возможности

- **Три режима** (взаимоисключающие, в меню):
  | Режим | Флаги `caffeinate` | Цвет иконки | Эффект |
  |-------|--------------------|-------------|--------|
  | **Выкл.** | — | серый | без предотвращения сна |
  | **Только простой** | `-i` | тёплый жёлтый | предотвращает сон при простое; экран может гаснуть |
  | **Простой + экран** | `-di` | насыщенный оранжевый | предотвращает сон **и** держит экран включённым |
- **Сессии с таймером** — не давать уснуть 30 мин / 1 ч / 2 ч, либо
  **Настроить…** (1–1440 минут). Таймер применяется к **текущему выбранному
  режиму** (или к последнему включённому). Пока он идёт, оставшееся время
  тикает в реальном времени рядом с чашкой (`12:34` или `1:23:45`) и в шапке
  меню; по истечении срока приложение само отключается.
- **Индикаторы агентов онлайн** — меню показывает, какие кодинг-агенты сейчас
  запущены, у каждого свой цветной кружок: 🟠 Claude · 🟢 Codex · 🔵 WorkBuddy ·
  🟣 ZCode · 🟡 OpenCode. Онлайн = горит; офлайн = строка полностью скрыта.
  Определение сканированием таблицы процессов (сравнение по basename, без
  учёта регистра) — обновляется при каждом открытии меню, в фоне раз в 60 с.
- **Глобальное сочетание клавиш** — `Ctrl+Alt+C` переключает три режима из
  любого приложения.
- **Авто: следить за агентами** *(по выбору)* — включает «Простой + экран»,
  пока запущен любой из пяти отслеживаемых агентов (Claude, Codex, WorkBuddy,
  ZCode, OpenCode), и выключает вскоре после их завершения.
- **Запуск при входе** — переключатель в меню (на основе LaunchAgent).
- **Двуязычный китайский/английский** — пункт меню «语言:中文 / Language:
  English» переключает интерфейс между китайским и английским одним кликом
  (меню, tooltip, обратный отсчёт); выбор сохраняется. Интерфейс приложения
  сейчас поддерживает китайский/английский.
- **Цветовая индикация** — чашка кофе (SF Symbol `cup.and.saucer.fill`)
  окрашивается через иерархическую конфигурацию символов — стабильно видна на
  всех версиях macOS (включая macOS 26 / Tahoe).
- **Никаких процессов-сирот.** Дочерний `caffeinate` отслеживается и
  завершается при каждом смене режима и при выходе/панике (гарантия `Drop`).
  Дочерние процессы также получают `-w <cafe pid>` — даже `kill -9` cafe не
  оставит «спасатель от сна» сиротой.
- **Честный интерфейс.** При открытии меню дочерний процесс перепроверяется;
  если `caffeinate` убили извне, иконка возвращается в «Выкл.», а не врёт.
- **Только строка меню.** Работает как accessory — без иконки в Dock, без
  главного окна.
- **Универсальный бинарник** — один `.app` для Apple Silicon и Intel Mac.

## Требования

- macOS 11.0 (Big Sur) или новее
- Rust 1.74+ (только для сборки из исходников)

## Установка

### Вариант A — собрать `.app`-бандл (рекомендуется)

```sh
git clone https://github.com/Anthemty/cafe.git
cd cafe
./make-app.sh          # создаёт dist/cafe.app
open dist/cafe.app
```

При первом запуске macOS может показать «cafe не может быть открыт, так как не
удалось проверить разработчика» (не подписан). Обход: правый клик по
приложению → **Открыть** → **Открыть** в диалоге. Разрешение запрашивается
один раз.

### Вариант B — запустить «сырой» бинарник

```sh
cargo build --release
./target/release/cafe
```

В строке меню появится чашка кофе. Кликните, выберите режим — Mac не уснёт,
пока вы не вернётесь в **Выкл.** или не выйдете.

> 💡 У «сырого» бинарника нет иконки приложения; для полного опыта (иконка,
> корректное имя в «Завершить принудительно», правильное поведение LSUIElement)
> используйте `make-app.sh`.

## Как это работает

cafe запускает и контролирует единственный дочерний процесс `caffeinate`,
перезапуская его с другими флагами при смене режима:

```
смена режима ──► Supervisor::enter(mode) ──► убить старый процесс ──► запустить новый
                                                  │
           (флаги caffeinate из Mode::caffeinate_args)
```

Супервизор — чистый Rust без зависимости от AppKit, полностью покрыт
юнит-тестами, где `sleep` подменяет `caffeinate`. Графический слой тонок:
`NSStatusItem` + `NSMenu`, чьи действия колбэка́т в супервизор.

## Структура проекта

```
src/
  main.rs         Настройка NSApp, элемент статус-бара + меню, колбэки действий
  supervisor.rs   Жизненный цикл дочернего caffeinate (spawn / kill / reap)
  state.rs        Enum Mode, сохранение конфига, обнаружение агентов
  icon.rs         Чашка SF Symbol + цвета режимов + точки агентов
make-app.sh       Сборка .app и генерация иконки приложения
resources/        Сгенерированные ресурсы иконок (AppIcon.icns)
```

## Почему не просто `caffeinate -i &`?

Можно — но вы забудете, что он запущен, уйдёте на ночь и вернётесь к горячему
ноутбуку с севшей батареей. cafe делает состояние **видимым** (цвет иконки), а
выключение — тривиальным.
